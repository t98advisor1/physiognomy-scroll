# 관상 연구소 — 사진으로 만드는 얼굴 지도

정식 주소: https://kwansang.vercel.app/

고등학생을 위한 모바일 우선 정적 웹앱. 시작 화면의 원근 투영 입체 격자 → 열화상 스타일 얼굴 지도 → 사진 촬영 → 사진의 선과 비율에 따른 16가지 시각 유형으로 이어진다. 설문과 API 연동을 제거했다. 얼굴로 성격·능력·건강·감정·운세를 추정하지 않는다.

## 촬영과 분류

MediaPipe Face Landmarker가 기기 내부의 전용 Worker에서 478개 지점을 추적한다. 전체 세부 격자와 46개 주요 지점, 눈·홍채·눈썹·코·입·윤곽선을 표시한다. 고정된 장식 지점을 실제 추적처럼 쓰지 않는다. 얼굴이 잡혀야 촬영 버튼이 켜지며, 촬영한 한 장을 다시 추적한 뒤 분류한다. 얼굴이 없거나 많이 잘리거나 크게 옆을 보면 재촬영을 안내한다. 일러스트 데모도 같은 촬영·모델 경로를 사용하며 데모라고 분명히 표시한다.

`photo-types.js`는 실제 사진의 픽셀 종횡비를 반영한 거리로 윤곽 4가지와 배치 4가지를 조합한다. 세로/가로, 아래 윤곽/너비, 눈 바깥 너비/얼굴 너비, 입 너비/얼굴 너비, 코 중심선/얼굴 세로 비율을 사용한다. 기준값은 예술적 시각 체험을 위한 휴리스틱이며 과학적으로 검증된 얼굴 분류나 진단이 아니다. 결과에 사용한 비율을 표시하며, 각도·표정·거리·조명·모델 오차에 따라 바뀔 수 있다. 확대·미러링은 화면 효과이며 분류 비율을 바꾸지 않는다.

사진·영상·좌표는 서버로 전송하거나 브라우저 저장소에 기록하지 않는다. 촬영본과 지점은 현재 페이지 메모리에만 있다. 결과로 이동하거나 백그라운드로 전환하면 카메라와 Worker를 종료한다. 다시 시작하면 촬영본을 지운다. 사용자가 이미지 저장 또는 인쇄를 누를 때만 파일로 남길 수 있다.

## 표시와 저장

- 열화상은 밝기를 보라·빨강·노랑으로 바꾸는 효과이며 실제 온도를 측정하지 않는다. 보이는 캔버스에 실사 원본을 직접 그리지 않는다.
- 모바일 결과 본문 19~23px, 문단 제목 18px. 전체 결과를 순차 타이핑하고 붓 모션·진행 막대·WebAudio 타이핑 소리를 함께 사용한다. 소리 ON/OFF, 한 번에 읽기, 다시 보기 지원. 사용자가 스크롤하면 자동 따라가기를 멈춘다. OS의 움직임 줄이기에서는 강한 장식 모션을 줄이되 글자 순차 출력은 유지한다.
- ‘결과 이미지 저장’은 사진의 열화상 지도와 완성된 전체 본문을 PNG로 만든다. 인쇄/PDF, 글 복사, 유형 이름·링크 공유도 지원한다.
- ‘프롬프트 복사 후 Gemini 열기’는 외부 Gemini 앱을 열고 질문을 클립보드에 복사한다. 사진·좌표·비율 수치는 프롬프트에 넣지 않는다. 자동 전송·API 호출·API 키 입력·답변 자동 수신은 없다.
- 요청 문구 `copyright ⓒ math-tong All right reserved.`를 화면 하단, 결과, PNG, 인쇄/PDF에 넣었다.
- OG 초상화 레이어 불투명도 30%, 공유 이미지 1200×630. canonical·OG·Twitter는 정식 Vercel 주소를 사용한다.

## 파일과 실행

`index.html`, `styles.css`, `app.js`, `photo-types.js`, `face-tracker.js`, `face-worker.js`, `models/face_landmarker.task`, `vendor/mediapipe/` 및 `assets/`가 필요하다. 로컬에서는 `python -m http.server 8000`으로 열고, 실제 카메라는 HTTPS 또는 localhost에서 이용한다. 워커·WASM·모델을 함께 배포해야 한다. `file://` 직접 실행은 지원하지 않는다.

런타임: @mediapipe/tasks-vision 1.2.0, Apache-2.0. 원본 라이선스와 출처는 `vendor/mediapipe/LICENSE.txt`, `vendor/mediapipe/NOTICE.txt`에 보관했다. SIMD 및 no-SIMD WASM을 함께 제공한다. 첫 실행에는 모델과 런타임을 내려받아 준비 시간이 필요하다. 추적 입력은 최대 너비 320px, 약 6.7Hz, 한 번에 한 프레임으로 제한해 UI와 분리한다. 화면 효과는 최대 약 20fps다.

Vercel 프로젝트 `kwansang`에 CLI 직접 배포한다. 별도 백엔드·데이터베이스·Cloudflare가 필요하지 않다. 소스 저장소는 https://github.com/t98advisor1/physiognomy-scroll 이며 Git 자동 배포 연결은 별도로 구성하지 않았다. 원본 및 이전 문답 데이터는 로컬 `원본/`에 보관하고 공개 배포에서 제외한다. `.env*`, `.vercel/`, 임시 파일은 배포·ZIP·Drive 복사 대상이 아니다.

## 읽기·출판 편집 개선

기본 타이핑은 90ms마다 한 글자이며 문장 끝은 추가 500ms, 문단 사이는 850ms 쉬어 간다. 160/90/75ms 속도와 일시정지·이어서 읽기를 선택할 수 있다. 일반 지점 반경 1.25px, 주요 지점 반경 3.2px로 확대했다.

관찰 기록을 실제 HTML 표로 표시한다. 저장·인쇄 구성은 표 중심 또는 2단 편집 중 선택하며 휴대폰 화면은 한 단을 유지한다. publication.js는 아이보리 바탕·청록 본문·골드 소제목의 PNG 리포트를 만든다. 줄바꿈은 단어를 우선하고, 문장부호가 혼자 남지 않도록 했다. A4 인쇄에서는 여백 13mm와 선택한 단 구성을 적용한다.

Gemini 프롬프트는 출판 편집자 역할, A4/모바일 판형, 2단 그리드, 정보 영역 6개, 관찰 표, 추상 도해, 색상, 글자 크기, 범례, 저작권 문구, HTML/SVG/PDF 산출 형태와 최종 점검 항목을 포함한다. 실제 Gemini의 파일 생성 가능 여부와 결과 품질은 서비스 환경에 따라 다르며 이 앱은 요청 문구를 복사하는 방식이다.

## Gemini 이미지 품질 개선

기본 프롬프트는 9:16 세로 이미지 한 장에 집중한다. 도해가 단순 도형 얼굴로 축소되지 않도록 익명의 입체 얼굴, 곡면을 감싸는 격자, 떠 있는 발광 지점, 곡선의 세 층과 열화상 그라데이션을 구체화했다. 화면 대부분을 대표 비주얼에 할당하고 본문은 제목·짧은 범례·제작 3단계로 줄였다. 여러 파일 형식과 원고 표를 이미지 요청에 함께 요구하지 않는다.

Gemini 영역의 ‘만들 결과물’에서 ‘이미지 한 장’ 또는 ‘인쇄용 HTML’을 선택한다. 인쇄 모드는 A4·2단·실제 텍스트와 인라인 SVG를 포함하는 HTML 코드 한 개를 요청한다. 두 요청은 별도 프롬프트로 생성되며 API 호출은 없다.

인포그래픽_개선예시_v2.png는 수정한 이미지 프롬프트로 내장 imagegen 도구에서 만든 방향 확인용 예시다. Gemini 서비스의 실제 생성 결과나 사용자의 촬영 사진이 아니다. 실제 출판 전에는 한글 교정, 저작권 기호, 폰트·자산 이용 권한, 인쇄 해상도를 확인해야 한다.

## 최종 읽기·이미지 요청 조정

기본 한 글자 간격은 90ms로 조정했으며 문장·문단의 쉼과 속도 선택은 유지했다. 이미지 프롬프트에 예시의 생생한 3D CGI 재질, 보라/주황/노랑의 곡면 조명, 금빛 궤도와 하단 3단계 미니어처 구성을 명시했다. ‘목표 이미지 예시 보기’에서 예시를 보고 저장하여 Gemini에 사용자가 직접 첨부할 수 있다. 예시 파일은 assets/infographic-example-v2.png다. 사진/좌표 전송 및 API 연동은 추가하지 않았다.
