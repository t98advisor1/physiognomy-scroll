# 관상 연구소 — 모바일 조선 캐릭터 탐험

사이트: https://kwansang.vercel.app/

첨부된 전체 HTML 앱을 바탕으로 재구성한 모바일 우선 정적 웹앱이다. 수묵 스튜디오, 선택형 카메라 화면 효과, 4문답, 16가지 캐릭터 교지, 도감, 텍스트 공유·복사·인쇄/PDF, 선택형 Gemini 앱 연동을 포함한다. 별도 서버나 API 키 없이 핵심 기능이 작동한다.

얼굴이나 운명을 분석하지 않는다. 결과는 답변 네 개의 이진 조합으로 결정하는 창작 이야기다. 카메라는 화면 효과 전용이며 사진·영상·좌표를 저장하거나 전송하지 않는다. 고등학생에게 맞춰 예언·재물운 대신 학습, 협업, 탐색과 작은 실천 중심으로 결과 문구를 다듬었다.

## 파일

- `index.html`: 화면 구조, canonical, Open Graph, Twitter Card
- `styles.css`: 모바일 우선 레이아웃, 접근성, 인쇄 스타일
- `data.js`: 4문답과 원본의 16종 캐릭터를 바탕으로 한 학생용 이야기
- `app.js`: 카메라, 3D 투영 캔버스, 문답, 공유, Gemini 프롬프트
- `assets/portrait.webp`: 제공된 초상화의 모바일용 압축본
- `assets/og-preview-v2.png`: 1200×630 공유 이미지. 초상화 레이어 불투명도 30%
- `assets/icon.svg`, `manifest.webmanifest`: 웹앱 아이콘 및 홈 화면 진입 정보
- `.nojekyll`: 정적 파일 제공 설정

## 개발과 배포

폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`을 연다. GitHub Pages는 `main` 브랜치 루트에서 자동 배포한다. 저장소 주소가 바뀌면 `index.html`의 canonical·OG·Twitter 이미지 URL과 `app.js`의 `SITE`를 함께 변경한다.

초상화는 원본 이미지의 내용을 변경하지 않고 WebP로 압축했다. 시작 화면 배경과 데모 캔버스는 불투명도 `0.30`으로 표시한다. 입체 효과는 가벼운 Canvas 2D의 원근 투영으로 구현했고, 동작 중인 화면만 최대 약 30fps로 그린다. 움직임 줄이기 설정을 따르며 상단에서 정지할 수 있다. 소리는 기본 OFF다.

Gemini 기능은 사용자가 직접 프롬프트를 복사해 별도 앱에서 이용하는 선택 기능이다. 붙여넣은 답변은 HTML이 아닌 텍스트로만 표시한다.

원본 HTML 및 이전 배포본은 로컬 `원본/` 폴더에 보관하고 공개 저장소 배포 대상에서 제외했다.
