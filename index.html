4문답의 16가지 조합을 16개 캐릭터에 연결합니다. 얼굴 모양, 피부색, 외모를 측정하거나 평가하지 않습니다. 과학적 성격 검사나 미래 예측이 아닙니다.

카메라는 선택, 얼굴은 내 기기에.

카메라는 실시간 화면 효과에만 사용합니다. 사진·영상·얼굴 좌표를 저장하거나 서버로 보내지 않습니다. 문답으로 이동하거나 화면을 벗어나면 카메라를 끕니다. 데모로도 모든 결과를 볼 수 있습니다.

나도, 친구도 한 가지 유형보다 큽니다.

등급 매기기나 외모 놀림 대신 서로 다른 강점을 이야기해 보세요. 결과 공유는 텍스트와 테스트 링크만 사용합니다.

움직임과 소리는 내가 선택해요.

상단 버튼으로 움직임을 멈추거나 효과음을 켤 수 있습니다. 소리는 기본적으로 꺼져 있습니다. 별도 회원가입이나 API 키가 필요하지 않습니다.
