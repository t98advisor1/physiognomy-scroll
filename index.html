16 VISUAL PORTRAITS

네 가지 윤곽, 네 가지 선.

사진 속 윤곽 4가지와 배치 4가지를 조합한 16가지 시각 유형이에요. 등급이나 성격 분류가 아닙니다.

얼굴 지도를 시작하기 전에

사진 속 선을 작품으로 만나요.

사진을 찍어야 유형이 나와요.

MediaPipe의 478개 얼굴 지점으로 윤곽과 눈·코·입의 비율을 계산해요. 설문 답변이나 무작위 결과는 쓰지 않습니다. 의학적 측정이나 과학적으로 검증된 얼굴 분류가 아닌 예술적 시각 체험입니다.

얼굴은 내 기기 안에서만.

사진·영상·얼굴 지점은 서버에 보내지 않아요. 촬영본은 현재 페이지 메모리에만 두고, 다시 시작하면 지웁니다. 직접 ‘결과 이미지 저장’이나 인쇄를 누를 때만 기기에 파일로 남길 수 있어요. 결과 화면으로 가거나 앱을 벗어나면 카메라를 끕니다. 열화상 색은 실제 온도가 아닌 밝기 기반 효과입니다.

사진이 말하지 못하는 것.

외모로 성격·능력·건강·미래를 판단하지 않습니다. 유형에 등급을 매기거나 친구의 외모를 놀리지 말고, 선과 색으로 만든 작품으로 즐겨 주세요.

큰 글씨, 모션, 소리.

결과는 큰 글씨와 붓 모션, 타이핑 소리로 순서대로 나타나요. 상단에서 소리를 끄거나 ‘한 번에 읽기’를 누를 수 있어요. Gemini는 프롬프트를 복사해 직접 이용하며 API 키는 사용하지 않습니다.
